# MiniAssist 1.5.0 — Fabric 1.21.4

Клиентский Fabric-мод для Minecraft 1.21.4 с многоколоночной ClickGUI, перетаскиваемым HUD-редактором, настройкой биндов и компактными панелями в духе Nursultan 1.16.5. Nursultan используется только как визуальный ориентир; исходный код и ресурсы не копируются.

## ClickGUI

- **Right Shift** — открыть или закрыть ClickGUI.
- Пять вертикальных категорий: Combat, Movement, Visuals, Player, Miscellaneous.
- Перетаскивай колонки за заголовок; расположение колонок сохраняется.
- **ЛКМ по модулю** — включить/выключить.
- **ПКМ по строке модуля** или кнопка `...` — развернуть настройки.
- Ползунки меняются перетаскиванием; чипы выбора переключаются кликом.
- Нажми на поле бинда, затем клавишу. **Delete/Backspace** очищает бинд, **Esc** отменяет назначение.
- Поиск фильтрует список модулей. Кликни поле поиска или нажми **Ctrl+F**.
- Config Manager: `SAVE` сохраняет конфигурацию, `RESET ALL` возвращает позиции HUD и колонок по умолчанию.
- Настройки, бинды и позиции интерфейса сохраняются в `config/miniassist.properties`.

## HUD и редактор

- **T** — открыть обычный чат Minecraft. Пока чат открыт, поверх игры появляется HUD Editor.
- Перетаскивай любую видимую HUD-панель **ЛКМ**. Отпусти кнопку, чтобы сохранить позицию.
- На верхней панели HUD Editor есть переключатели **HUD ON/OFF** и **BINDS ON/OFF**, а также **RESET** для сброса позиций HUD.
- Список биндов можно отдельно скрыть кнопкой `BINDS` в HUD Editor либо в ClickGUI: Visuals → HUD → `Список биндов`.
- **G** — скрыть/показать весь кастомный HUD.
- **Right Shift** открывает ClickGUI; после закрытия чата HUD Editor исчезает.

Панели HUD: watermark/FPS/ping, активные модули, список биндов, координаты/скорость/направление, броня/прочность, эффекты, Target HUD и Keystrokes. Каждая панель включается/выключается в Visuals → HUD; расположения запоминаются.

## Модули

- **Aim Assist (F6)** — плавное наведение на выбранную видимую цель с настройками FOV, дистанции и скорости. Цели выбираются локально; модуль не наводится через стены.
- **TriggerBot (F7)** — проверка цели под прицелом по игровым тикам с учётом ванильного кулдауна и дополнительной задержки в тиках.
- **FreeCam (F8)** — отделяет камеру от персонажа, использует назначенные в Minecraft клавиши движения и возвращает состояние при выключении/отключении от сервера.
- **HUD (G)** — настраиваемые панели интерфейса.

Бинды F6/F7/F8 можно переназначить в ClickGUI. G зарезервирована для показа/скрытия HUD. Multiplayer-серверы могут запрещать combat-assistance моды; соблюдай правила сервера.

## Сборка на GitHub

1. Загрузи содержимое ZIP прямо в корень репозитория. В корне должны находиться `build.gradle`, `gradle.properties`, `settings.gradle`, `src/` и `.github/workflows/build.yml`.
2. Сделай Commit/Push в любую ветку.
3. Открой **Actions → MiniAssist Build**.
4. При успешном запуске скачай **Artifacts → MiniAssist-1.5.0** и распакуй `zenith-client-1.5.0.jar`.
5. Если сборка завершилась ошибкой, скачай `MiniAssist-build-log`, если он был создан, и передай лог для диагностики.

Workflow использует Temurin Java 21, Gradle 8.12, Fabric Loom 1.10.5, Minecraft 1.21.4, Yarn `1.21.4+build.8`, Fabric Loader 0.16.9 и Fabric API `0.112.2+1.21.4`. Локальный Gradle Wrapper не требуется.

## Примечание

Это версия для **Minecraft 1.21.4**, не порт на Minecraft 1.16.5. Стиль интерфейса вдохновлён компоновкой с отдельными колонками категорий и компактными тёмными HUD-панелями на предоставленном скриншоте.
