MINIASSIST 1.5.0 — СНАЧАЛА ПРОЧИТАЙ

1) Распакуй ZIP.
2) Загрузи ВСЁ содержимое архива в корень GitHub-репозитория.
   В корне должны быть build.gradle, gradle.properties, settings.gradle, src/ и .github/workflows/build.yml.
   Не загружай сам ZIP как один файл и не помещай проект во вложенную папку.
3) Сделай Commit / Push в любую ветку.
4) Открой Actions → MiniAssist Build.
5) При зелёной сборке скачай Artifacts → MiniAssist-1.5.0. Внутри будет zenith-client-1.5.0.jar.
6) При красной сборке скачай MiniAssist-build-log, если он появился, и передай его для диагностики.

HUD EDITOR:
- Нажми T, чтобы открыть чат Minecraft.
- Перетаскивай HUD-панели левой кнопкой мыши.
- В верхней панели можно включать/выключать весь HUD и список биндов.
- RESET возвращает позиции HUD по умолчанию.

CLICKGUI:
- Right Shift — открыть меню.
- Перетаскивай категории за заголовок.
- ЛКМ по модулю — включить/выключить; ПКМ — раскрыть настройки.
- Клик по бинду, затем клавиша; Delete очищает.
- Config Manager → SAVE сохраняет; RESET ALL сбрасывает расположение.
